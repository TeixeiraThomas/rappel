# Modules de formation — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** catalogue de modules prêts à l'emploi (cloud, permis, réseau, sécurité, méthodes, secourisme) ajoutables en un geste.

**Architecture:** métadonnées dans `src/modules/catalog.ts`, contenu par module dans `src/modules/data/<id>.ts` chargé par
`import()` ; `src/lib/library.ts` crée paquets/notes/cartes en une transaction ; écran `src/pages/Library.tsx` (`#/library`).

**Tech Stack:** React 19, Dexie 4, Vitest 5 (+ jsdom pour le SVG), Playwright, Vite 8 + vite-plugin-pwa.

**Spec:** `docs/superpowers/specs/2026-11-26-modules-design.md`

## Global Constraints

- Interface et contenu en français ; termes d'examen anglais conservés entre parenthèses quand l'examen est en anglais.
- Cartes : réponse courte d'abord, explication entre parenthèses ; pas de `::` dans les noms de chapitres.
- Aucun contenu copié d'une banque de questions protégée ; panneaux dessinés en SVG simplifiés.
- Le bundle principal ne doit pas grossir du contenu des modules (un chunk par module).
- Ne jamais écraser une note modifiée par l'utilisateur (`updated !== created`).

## Review Focus

- Module ajouté deux fois → aucun doublon (test `réajout sans doublon`).
- Utilisateur a renommé/déplacé le paquet du module puis met à jour → les cartes manquantes sont recréées sous le chemin d'origine, rien n'est supprimé (test `mise à jour après renommage`).
- Note du module modifiée par l'utilisateur → la mise à jour ne la touche pas (test `respecte les notes modifiées`).
- SVG d'un panneau mal formé → test `chaque SVG est bien formé` (DOMParser jsdom).
- Compteur du catalogue faux après une modification de contenu → test `compteurs du catalogue exacts`.

### Task 1: Format, catalogue et installation

**Files:** Create `src/modules/types.ts`, `src/modules/catalog.ts`, `src/lib/library.ts`, `src/lib/library.test.ts`.

**Interfaces (Produces):**
- `type ModuleCard = [front: string, back?: string]` (recto à trous `{{cN::…}}` → note cloze, `back` = extra).
- `interface ModuleChapter { title: string; tag: string; cards: ModuleCard[] }`
- `interface ModuleContent { chapters: ModuleChapter[] }`
- `interface ModuleMeta { id; title; deckName; category: ModuleCategory; description; exam: {label: string; value: string}[]; version: string; notes: number; cards: number; tags: string; load(): Promise<ModuleContent> }`
- `CATEGORIES: {id: ModuleCategory; label: string}[]`, `MODULES: ModuleMeta[]`
- `moduleNotes(meta, content): NoteInput-like[]` (pure), `installModule(meta, content): Promise<{added; updated; rootDeckId}>`,
  `installedCount(tag): Promise<number>`

- [ ] Tests : ajout crée `deckName::1. Chapitre`, tags `[meta.tags, chapter.tag]`, ordre des `due` = ordre du programme ; réajout sans doublon (added 0) ; respecte les notes modifiées ; corrige le verso d'une note non modifiée ; mise à jour après renommage.
- [ ] Implémenter ; `npm test -- library` vert.
